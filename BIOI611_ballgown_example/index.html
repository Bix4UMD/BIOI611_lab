Isoform-level differential expression analysis with Ballgown.

This notebook is based on the reference: https://www.bioconductor.org/packages/release/bioc/vignettes/ballgown/inst/doc/ballgown.html

Before you begin

This notebook starts with precomputed transcript-assembly results; it does not begin with FASTQ files. The upstream workflow is: align RNA-seq reads, provide or assemble a transcriptome, quantify transcripts and splice features for every sample, and organize those measurements into the .ctab files used below. The example files are already included with the Ballgown package.

Reproducibility note: Ballgown is now a legacy workflow and is marked deprecated/removed in current Bioconductor releases. The saved output in this notebook was generated with Bioconductor 3.22. A fresh Colab runtime may therefore require a compatible environment, and installation can take 15–20 minutes. We use the notebook as a clear teaching example of transcript-level analysis.

By the end, you should be able to identify what is stored in a Ballgown object, attach sample metadata safely, visualize assembled transcripts, run a transcript-level differential-expression test, and interpret p-values, q-values, and fold changes without confusing transcript abundance with isoform usage.

How to interpret the sample folders

Each sample has its own folder, and every folder must describe features from the same reference or merged transcript set.

  • t_data.ctab contains transcript-level abundance and structure.
  • e_data.ctab contains exon-level measurements.
  • i_data.ctab contains splice-junction support. Here, "intron" refers to the genomic interval spanned by a splice junction; it is not automatically evidence of intron retention.
  • e2t.ctab and i2t.ctab connect exons and junctions to their transcripts.

ballgown() combines these files across samples; it does not estimate expression directly from FASTQ files. StringTie can generate the tables after re-estimating all samples against a common GTF, typically with -e plus -B or -b.

expr

The expr slot is a list that contains tables of expression data for the genomic features. These tables are very similar to the *_data.ctab Tablemaker output files. Ballgown implements the following syntax to access components of the expr slot:

*expr(ballgown_object_name, <EXPRESSION_MEASUREMENT>)

where * is either e for exon, i for intron, t for transcript, or g for gene, and is an expression-measurement column name from the appropriate .ctab file. Gene-level measurements are calculated by aggregating the transcript-level measurements for that gene. All of the following are valid ways to extract expression data from the bg ballgown object:

transcript_fpkm = texpr(bg, 'FPKM')
transcript_cov = texpr(bg, 'cov')
whole_tx_table = texpr(bg, 'all')
exon_mcov = eexpr(bg, 'mcov')
junction_rcount = iexpr(bg)
whole_intron_table = iexpr(bg, 'all')
gene_expression = gexpr(bg)

Checkpoint: verify the sample metadata

pData(bg) tells Ballgown which biological group each sample belongs to. Its rows must be in exactly the same order as sampleNames(bg). An ordering error can silently assign samples to the wrong group.

Run this check before performing a statistical test:

stopifnot(
  identical(as.character(pData(bg)$id), sampleNames(bg))
)

table(pData(bg)$group)

For a real experiment, join metadata by sample ID rather than assuming directory order. Use informative group labels and include relevant variables such as batch, sex, or age when appropriate.

Plotting transcript structures

    meas='FPKM', colorby='transcript',
    main='transcripts from gene XLOC_000454: sample 12, FPKM')

It is also possible to plot several samples at once:

plotTranscripts('XLOC_000454', bg,
    samples=c('sample01', 'sample06', 'sample12', 'sample19'),
    meas='FPKM', colorby='transcript')

You can also make side-by-side plots comparing mean abundances between groups (here, 0 and 1):

plotMeans('XLOC_000454', bg, groupvar='group', meas='FPKM', colorby='transcript')

Interpreting the transcript plots

These plots are descriptive:

  • plotTranscripts() shows assembled transcript structures and estimated abundance.
  • plotMeans() compares average abundance between groups.
  • Colors and heights are based on FPKM estimates; they are not measures of statistical significance and do not display replicate variability.

Transcripts that share many exons can be difficult to quantify separately with short reads. Confirm a visual difference with the statistical results, and do not describe a transcript as completely present or absent from these plots alone.

Differential expression analysis

Ballgown provides a wide selection of simple, fast statistical methods for testing whether transcripts are differentially expressed between experimental conditions or across a continuous covariate (such as time).

What does stattest() test?

With feature = "transcript" and meas = "FPKM", Ballgown tests each transcript for a difference in abundance between groups. By default, it:

  • models log2(FPKM + 1);
  • compares nested linear models with an F-test;
  • applies its own library-size adjustment; and
  • reports a raw p-value and a multiple-testing-adjusted q-value.

This is transcript-level differential expression, not a negative-binomial count test and not automatically differential transcript usage. A transcript may change because the entire gene changes. To argue for an isoform-composition change, compare the transcript with the other isoforms from the same gene and examine relative usage or splice-junction evidence.

For a real transcriptome, define a low-expression filter before testing so that nearly unobserved transcripts do not add uninformative tests.

stat_results = stattest(bg, feature='transcript',
                   meas='FPKM', covariate='group',
                   getFC=TRUE)

Interpreting the results table

Use qval, rather than the raw pval, to decide which transcripts pass a stated false-discovery-rate threshold. For example:

alpha <- 0.05

significant_transcripts <- subset(
  results_transcripts,
  !is.na(qval) & qval < alpha
)

nrow(significant_transcripts)
head(significant_transcripts[order(significant_transcripts$qval), ], 10)

Under this rule, a transcript with qval >= 0.05 is not called significant. The fc column is an estimated fold change, not a log2 fold change. Its direction follows the group reference level, so state the contrast explicitly before saying which group is higher.

What can we conclude for XLOC_000101?

This locus contains two assembled transcripts. One transcript has a small q-value and a large estimated fold change, whereas the other does not show strong evidence of differential expression. This is evidence for transcript-specific behavior, but it does not by itself prove an isoform switch.

Before making that claim, ask:

  • Does total expression of the gene change?
  • Does each transcript's proportion within the gene change?
  • Are the transcripts sufficiently distinct to be quantified reliably?
  • Do splice-junction reads support the proposed transcript difference?

XLOC_* and TCONS_* are assembly-generated identifiers from this example. Blank gene names are expected when an assembled transcript has not been matched to an annotated gene symbol.

Final checklist

Before interpreting or reporting the results, confirm that you have:

  • loaded all intended sample folders;
  • checked that pData(bg) and sampleNames(bg) are in the same order;
  • verified the number of samples in each group;
  • considered relevant batch variables or confounders;
  • stated the FDR threshold and used qval, not only the raw p-value;
  • stated the direction of the fold-change contrast;
  • distinguished transcript differential expression from differential transcript usage;
  • treated the plots as supporting visualization rather than as the statistical test; and
  • recorded the software environment for reproducibility.
